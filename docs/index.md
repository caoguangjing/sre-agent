# 智能运维平台

智能运维平台提供中文聊天、知识库、MCP 工具管理和智能诊断。后端使用 Java 17、Spring Boot 与 AgentScope，前端使用 Vue 3；SQLite 保存业务与任务，Milvus 保存知识向量。
